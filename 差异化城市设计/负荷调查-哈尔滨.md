# 负荷调查 — 哈尔滨（差异化设计 · 严寒地区采暖版）

> 依据：课程设计任务书 §3.1「标准化家庭负载估算与日均能耗计算工作表」；设计指导书 §2（计算口径、表1 建议范围）。每台设备落实到具体品牌型号与官方/可检索参数（来源见 §7）。
> 状态：已完成（2026-09-03 完善至与深圳/拉萨同级详细度，覆盖 D3 检查点②交付要求）。
> 设计点：**冬季采暖季 E_AC = 7.82 kWh/d**（对应任务书负荷区间 **7.5~8.0 kWh/d，学号末位 4/5**；如你的分配区间不同，可按 §8 微调设备运行时间）。

## 0. 基本条件与假设（哈尔滨差异化核心）

| 项目 | 取值 | 说明 |
|------|------|------|
| 设计城市 | 哈尔滨（45.80°N、126.53°E，平原） | **严寒地区**，中温带大陆性季风气候，冬季长而寒冷 |
| 家庭结构 | 3 口之家（假定） | 同深圳示例口径 |

| 能量口径 | 交流侧日用电量 E_AC | 蓄电池公式直接使用 E_AC，不重复除以逆变器效率（指导书 §2.2） |
| **季节性负荷结构（冬夏双峰）** | 与拉萨「只有冬季采暖」不同、与深圳「只有夏季空调」不同——哈尔滨**冬季电采暖 + 夏季空调**双峰（7 月均温约 24.0 ℃，夏季确有空调需求） | 本设计的差异化主线（答辩重点） |

| 过渡月 | 4 月、10 月（月均温 5.8~6.7 ℃，早晚仍冷） | 仅用电热毯 |
| 夏季空调 | 6–8 月午后短时使用（变频 1.5P），4 h/d × 运行系数 0.5 | 哈尔滨 7 月均温约 24.0 ℃，空调需求比兰州（20.7 ℃）更强，运行系数取 0.5 |

| **严寒（哈尔滨差异化）** | 极端最低 **-38.1 ℃**：设备间保温 ≥10 ℃ + 低温加热为蓄电池硬性前提（W4 详述）；屋面雪荷载与防冻（W8） | 全团队最严酷，冬季可靠性是本设计最大差异化点 |

## 2. 分类小计与建议范围对照（指导书 §2.1 表 1）— 冬季口径

| 类别 | 本方案(kWh/d) | 建议范围(kWh/d) | 结论 |
|------|--------------|-----------------|------|
| 制冷和空调 | 0.54（冬季无空调，仅冰箱） | 3.3 ~ 5.0 | 偏离（见说明） |
| **采暖（哈尔滨冬季替代空调的位置）** | **4.20** | — | 新增季节性大项（严寒城市） |
| 照明 | 0.38 | 0.3 ~ 0.6 | ✅ |
| 通信和信息设备 | 0.97 | 0.8 ~ 1.4 | ✅ |
| 基本炊事 | 1.15 | 0.7 ~ 1.2 | ✅ |
| 生活辅助 | 0.57 | 0.5 ~ 1.0 | ✅ |
| **合计（冬季设计点）** | **7.82** | 6.5 ~ 8.5 | ✅ |

> **关于「制冷和空调」偏离说明（答辩重点）**：表1 的建议范围基于**含空调的普通家庭**。哈尔滨冬季（设计点口径）无空调运行，制冷类别仅冰箱 0.54——该类别在哈尔滨是「**冬夏双峰**」：夏季（6–8 月）空调按 845 W×4 h×0.5 = 1.69 kWh/d 计入（7 月均温约 24.0 ℃，四城中空调需求最强），冬季位置由采暖 4.20 kWh/d 承接。指导书 §2.1 明确"各项范围用于帮助检查总量是否合理，不要求机械取中值"，且冬季合计 7.82 在分配区间内，符合任务书要求。

> 电热水壶（19:00–19:15）与电饭煲、电暖器叠加形成冬季峰值——已在表中体现（指导书 §2.3 要求，不能只在文字中说明）。
> 冬季夜间日照极少（16:00 后天黑），晚间负荷集中由蓄电池经逆变器供电，24 h 表的晚间峰谷对离网容量设计很关键（与深圳晚 19:00 后负荷集中类似，但哈尔滨冬季夜间更长）。

## 4. 最大同时功率（含周末校核，指导书 §2.3）

- **冬季工作日**峰值：19:00–19:15 烧水时段 = 电暖器 1.2 + 电热毯 0.15 + 水壶 1.8 + 电饭煲 0.86 + 油烟机 0.26 + 照明 0.10 + 电视 0.11 + 冰箱 0.12 + 路由 0.01 ≈ **4.6 kW**；
- **周末校核**：电磁炉安排周末**午餐**（12:00–13:00，电暖器未开）：2.1 + 0.86（电饭煲）+ 0.26（油烟机）+ 0.10 + 0.11 + 0.12 + 0.01 ≈ **3.6 kW**，低于冬季工作日峰值；
- **结论：P_max ≈ 4.6 kW**（冬季电采暖 + 炊事峰值；夏季空调峰单独校核：空调 0.845×0.5+基础 ≈ 0.9 kW，远低于冬季峰值——逆变器由冬季口径决定）。

## 5. 短时冲击功率

| 启动设备 | 启动倍数 | 短时功率(kW) | 说明 |
|---------|---------|-------------|------|
| 冰箱压缩机 | 约 5 倍（~120 W 额定） | 0.60 | 间歇启动 |
| 空调（变频，仅夏季） | 低倍数 | — | 变频软启动，不套定频 5~7 倍（指导书 §2.4） |
| 洗衣机甩干 | 短时峰值 | 1.00 | 15:00 时段，不与炊事高峰重叠 |
| 电暖器/电热毯/水壶/电磁炉 | 阻性无冲击 | — | 电阻负载无启动冲击 |

- 最不利组合：冬季烧水高峰 + 冰箱压缩机启动：P_short ≈ 4.6 + 0.6 ≈ **5.2 kW**；
- **结论：系统短时冲击功率 ≈ 5.2 kW**（用于逆变器短时功率校核，指导书 §7.2）。

## 8. 待确认事项

1. **学号末位对应的负荷区间**：本方案按 7.5~8.0 kWh/d（学号末位 4/5）设计；如你的区间不同（如 6.5~7.0），可把电暖器日耗电从 3.00 调至 2.20（1.2 kW×3.7 h×0.5）→ 冬季 E_AC≈7.0，各章同步微调；
2. 家庭结构（3 口之家）与住宅面积、屋面形式（影响 W8 阵列布置与雪荷载校核）；
3. 电热毯/电暖器具体型号替换（功率口径不变）；
4. 夏季空调（6–8 月午后 4 h×0.5）是否符合本人生活习惯，可调（哈尔滨 7 月均温约 24.0 ℃）；
5. **城市集中供暖讨论（答辩点）**：哈尔滨城区冬季普遍有市政集中供暖；本任务按「离网自备电采暖」场景设计（任务书统一要求电负荷自理），若实际住宅接入市政供暖，采暖负荷可大幅下调（E_AC 将降至约 3.6 kWh/d 级，系统规模显著缩小）——该讨论不改变本设计口径，仅供答辩说明。
