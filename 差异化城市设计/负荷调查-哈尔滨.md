# 负荷调查 — 哈尔滨（差异化设计 · 严寒地区采暖版）

> 依据：任务书 §3.1、指导书 §2。状态：本地草稿。设计点：冬季采暖季 E_AC = 7.82 kWh/d（对应区间 7.5~8.0，学号末位 4/5，可按区间微调）。

## 0. 基本条件（哈尔滨差异化核心）

| 项目 | 取值 | 说明 |
|------|------|------|
| 设计城市 | 哈尔滨（45.80°N、126.53°E，平原） | **严寒地区**，冬季长而寒冷 |
| 气候 | 中温带大陆性季风 | 1 月均温约 -18.4 ℃，7 月约 24.0 ℃ |
| 季节性负荷 | 冬季电采暖（11–3 月）+ 夏季轻度空调（6–8 月） | 冬夏都有热/冷需求（与拉萨只有采暖不同） |
| 采暖 | 电热毯 0.15 kW×8 h + 对流式电暖器 1.2 kW×5 h×0.5 | 严寒城市冬季必需，总量仍控制在区间内 |
| 空调 | 6–8 月午后 4 h×0.5（变频 1.5P，845 W） | 哈尔滨夏季最热月均温 24 ℃，空调合理 |

- 采暖季（11–3 月）E_AC = 7.82（区间 7.5~8.0 ✅）；过渡月（4、10）4.82；夏季（6–8）5.31；温和月（5、9）3.62。

## 2. 最大同时功率与短时冲击

- 冬季峰值（19:00–19:15 烧水 + 电暖器 + 电热毯 + 电饭煲 + 油烟机 + 照明 + 电视 + 冰箱 + 路由）≈ **4.6 kW**；
- 周末电磁炉安排午餐（电暖器未开）≈ 3.6 kW < 4.6 kW；
- **P_max ≈ 4.6 kW**；P_short = 4.6 + 冰箱启动 0.6 ≈ **5.2 kW**。

## 3. 输出汇总

| 结果 | 数值 |
|------|------|
| E_AC（冬季设计点） | **7.82 kWh/d** |
| E_AC（过渡/夏季 AC/温和） | 4.82 / 5.31 / 3.62 kWh/d |
| P_max | 4.6 kW |
| P_short | 5.2 kW |

> 哈尔滨与拉萨差异点：冬季都用电采暖，但哈尔滨**夏季（6–8 月）也有空调需求**（7 月均温 24 ℃），季节负荷「冬季采暖 + 夏季空调」双峰；冬季严寒（1 月均温 -18.4 ℃）使采暖负荷是刚需。
