## 2. 蓄电池配置说明（任务书 §4.8）

- **方案 A（采用）**：5×BNP-5120BM（100 Ah）= 25.60 kWh，电池成本 **¥20,000**，支路保护 5 路；W5~W9 校核与图纸均按此配置；
- **方案 B（200 Ah）在本方案不可行**（W4 §4，同拉萨/兰州）：2 台 20.48 kWh < 下限 21.64 kWh 不足；3 台 30.72 kWh 超 1.25 倍上限（1.42 倍）——"夹逼困境"。

## 3. 成本分析（指导书 §12.1）

| 指标 | 数值 |
|------|------|
| 系统初始总投资 | **≈ ¥42,592** |
| 单位装机成本 | ≈ ¥42,592 / 6.00 kWp = **¥7.10/Wp** |
| 单位储能成本 | ¥20,000 / 25.60 kWh ≈ **¥781/kWh**（仅电池） |
| 成本结构 | 蓄电池 47%（含柜体/保温/母排）＞ 光伏阵列 15%（10 块）＞ 控制变换 11%（双机）＞ 支架 7% ＞ 其余 20% |

> 哈尔滨为四城最高（深圳 ¥26,945、拉萨 ¥32,740）：多 5 块组件（+¥3,250）、多 1 台逆变器（+¥2,400）、双机保护器件加倍（+~¥700）、大倾角支架（+¥1,500）、保温+加热设备间（+¥1,500）；但单位装机 ¥7.10/Wp 为四城**最低**（规模效应），电池占比 47% 较其他城市低（光伏/双机拉高了总盘子）。

## 4. 成本过高检查（指导书 §12.2 顺序）

1. 负荷在分配区间且采暖时长合理 ✅（E_AC=7.82∈[7.5,8.0]，电暖器 5 h×0.5）；
2. 未把 3 d 作为基准容量 ✅；未重复计算损失 ✅；
3. 电池粒度已论证（方案 B 失效，见 §2）；未以取消保护/扩大 DOD/超电流限值降本 ✅；
4. 哈尔滨特有降本点：**设备间保温 + 低温加热（¥1,500）绝对必要**——不保温 K_T=0.70 → 需 7 台电池，多 ¥8,000，得不偿失；若可省，优先：组件低价期采购 → 保温自装/加热器选小功率 → 支架自装 → **不省双机**（输入侧电流约束，不可省）；
5. 双机成本说明：2 台 SPF 5000 ES 并联非负荷所需（单台 5 kW＞P_max=4.6 kW），但 6.00 kWp 两串并联输入电流 28.98 A＞单台 MPPT 22 A 限值，**双机是光伏输入侧的硬约束**，不可降为单机。
