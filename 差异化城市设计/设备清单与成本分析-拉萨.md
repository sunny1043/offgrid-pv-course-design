## 2. 蓄电池配置说明（任务书 §4.8）

- **方案 A（采用）**：5×BNP-5120BM（100 Ah）= 25.60 kWh，电池成本 **¥20,000**，支路保护 5 路；W5~W9 校核与图纸均按此配置；
- **方案 B（200 Ah）在本方案不可行**（W4 §4）：2 台 20.48 kWh < 下限 21.64 kWh 不足；3 台 30.72 kWh 超 1.25 倍上限（1.42 倍）——拉萨冬季电采暖抬高容量下限后出现"夹逼困境"，故无 B 备选可比（与深圳不同）。

## 3. 成本分析（指导书 §12.1）

| 指标 | 数值 |
|------|------|
| 系统初始总投资 | **≈ ¥32,740** |
| 单位装机成本 | ≈ ¥32,740 / 3.00 kWp = **¥10.9/Wp** |
| 单位储能成本 | ¥20,000 / 25.60 kWh ≈ **¥781/kWh**（仅电池） |
| 成本结构 | 蓄电池 64%（含柜体/保温）＞ 光伏阵列 12% ＞ 控制变换 7% ＞ 其余 17% |

> 拉萨因多 1 台电池 + 保温，总投资高于深圳（¥26,945）约 ¥5,800；电池占比仍约 2/3（离网典型特征）。

## 4. 成本过高检查（指导书 §12.2 顺序）

1. 负荷在分配区间且采暖时长合理 ✅（E_AC=7.82∈[7.5,8.0]，电暖器 5 h×0.5）；
2. 未把 3 d 作为基准容量 ✅；未重复计算损失 ✅；
3. 电池粒度已论证（方案 B 失效，见 §2）；未以取消保护/扩大 DOD/超电流限值降本 ✅；
4. 拉萨特有降本点：**设备间保温（¥800）是必要的**（不保温 K_T=0.70 → 需 7 台电池，多 ¥8,000，得不偿失）；若可省，优先：组件低价期采购 → 保温自装/简化电伴热 → 支架自装；
5. SPF 5000 ES 高原额定若不足 4.6 kW 需上调机型（成本 +¥500~1,000），W12 前向厂家确认。
