# 蓄电池设计 — 哈尔滨（W4）

> 依据：指导书 §5、任务书 §4.3。状态：本地草稿（配套 Excel docs/计算-蓄电池-哈尔滨.xlsx）。
> 拉萨差异化：同拉萨，容量由冬季电采暖负荷驱动（21.64 kWh / 5 台）；但哈尔滨低温更极端（-38.1 ℃），**设备间保温/加热是硬性前提**（否则 LFP 无法正常充放电），低温敏感性比拉萨更突出。

## 1. 设计输入

| 输入 | 取值 | 来源 |
|------|------|------|
| E_AC | 7.82 kWh/d（冬季） | W1 |
| eta_inv | 0.93 | W3（SPF 5000 ES） |
| eta_dis | 0.95 | W3 |
| P_max / P_short | 4.6 / 5.2 kW | W1 |
| K_T 低温修正 | 1.00（设备间保温不低于 10 ℃，**哈尔滨为必须**） | 见 §3/§8 |

## 2. 最低标称能量

    E_bat,min = 7.82 * 2 * 1.10 / (0.90 * 0.95 * 0.93 * 1.00) = 21.64 kWh
    C_bat,min = 1000 * 21.64 / 51.2 = 422.6 Ah

| 系数 | 取值 | 依据 |
|------|------|------|
| N_A | 2 d | 任务书基准 |
| K_R | 1.10 | 指导书 §5.2 |
| DOD | 0.90 | 磷酸铁锂+BMS（保守 0.80 见 §8） |
| K_T | 1.00 | 保温设备间不低于 10 ℃ |

## 3. 模块选型与串并联（方案 A：BNP-5120BM × 5）

- E_mod = 5.12 kWh；N_P = ceil(21.64/5.12) = **5 台**；实际 25.60 kWh，为下限 **1.18 倍**（≤1.25 ✅）；
- 方案 B（200 Ah）：2 台 20.48 < 21.64（不足）；3 台 30.72 = 1.42×（超上限）——**失效**（同拉萨，深圳可行、哈尔滨不可行）。

## 4. 放电与充电电流校核

逆变器：哈尔滨采用 **2× Growatt SPF 5000 ES 并联**（原因见 W6：单台 MPPT 电流限值 22 A 容不下 6.0 kWp 两串并联），共用 48 V 电池母线：

- 连续放电电流（两台逆变器全额定最不利）：I_dis = 2×5000/(45×0.93) = **238.9 A**；
- 短时放电电流：I_dis,sur = 5200/(45×0.93) = **124.3 A**；
- 最大充电电流：I_chg = min(6000×0.96/54.4, 2×100) = **105.9 A**。

| 校核项 | 需求 | 能力（5×BNP-5120BM） | 结论 |
|--------|------|----------------------|------|
| 连续放电 | 238.9 A | 500 A | ✅ 裕量 2.1× |
| 短时放电 | 124.3 A | 500 A | ✅ |
| 最大充电 | 105.9 A | 250 A | ✅ 裕量 2.4× |

## 5. 敏感性复核（差异化重点）

| 口径 | E_bat,min | 台数 |
|------|-----------|------|
| 3 d 自主供电 | 32.45 kWh | 7 |
| DOD=0.80 保守 | 24.34 kWh | 5 |
| **K_T=0.70（设备间不保温，约 0 ℃）** | **30.91 kWh** | **7** |
| 备注（哈尔滨极端） | 若设备间降到 -20 ℃，LFP 容量损失过半且低温禁充，方案需根本调整 | — |

> **结论**：哈尔滨 -38.1 ℃ 极端低温下，**设备间保温 + 低温加热是必须项**（否则蓄电池无法满足冬季夜间放电后次日白天充电）。不保温敏感性 K_T=0.70 时需 7 台（+43% 容量，多 2 台约 0.7~1 万元）——比拉萨更刚性。

## 6. 输出汇总

| 项目 | 结果 |
|------|------|
| 最低标称能量 | 21.64 kWh |
| 配置 | BNP-5120BM × 5（N_S=1，N_P=5），25.60 kWh |
| 连续/短时/充电电流 | 238.9 / 124.3 / 105.9 A |
| 设备间保温 | 必须（不低于 10 ℃）+ 低温加热 |
| 红线自查 | N_S=1 不串联；I_chg 按 MPPT 输出侧算；E_AC 不重复除以 eta_inv；实际能量 1.18×≤1.25 ✅ |
