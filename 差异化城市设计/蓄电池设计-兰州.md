# 蓄电池设计 — 兰州（W4）

> 依据：指导书 §5、任务书 §4.3。状态：本地草稿（配套 Excel docs/计算-蓄电池-兰州.xlsx）。
> 兰州差异化：容量由冬季电采暖驱动（21.64 kWh / 5 台，同拉萨/哈尔滨）；低温 -23.1 ℃，设备间保温不低于 10 ℃ 为必须，低温敏感性（K_T=0.70 时 30.91 kWh / 7 台）介于拉萨与哈尔滨之间。

## 1. 设计输入

| 输入 | 取值 | 来源 |
|------|------|------|
| E_AC | 7.82 kWh/d（冬季） | W1 |
| eta_inv / eta_dis | 0.93 / 0.95 | W3 |
| P_max / P_short | 4.6 / 5.2 kW | W1 |
| K_T | 1.00（设备间保温不低于 10 ℃） | 见 §5/§8 |

## 2. 最低标称能量

    E_bat,min = 7.82 * 2 * 1.10 / (0.90 * 0.95 * 0.93 * 1.00) = 21.64 kWh
    C_bat,min = 1000 * 21.64 / 51.2 = 422.6 Ah

## 3. 模块选型与串并联（方案 A：BNP-5120BM × 5）

- E_mod = 5.12 kWh；N_P = ceil(21.64/5.12) = **5 台**；实际 25.60 kWh = 下限 **1.18 倍**（≤1.25 ✅）；
- 方案 B（200 Ah）：2 台不足（20.48<21.64）、3 台超上限（30.72=1.42×）——**失效**（同拉萨/哈尔滨）。

## 4. 放电与充电电流校核（单台 SPF 5000 ES，P_PV=3.60 kWp）

- 连续放电：I_dis = 5000/(45×0.93) = **119.5 A**；
- 短时放电：I_dis,sur = 5200/(45×0.93) = **124.3 A**；
- 最大充电：I_chg = min(3600×0.96/54.4, 100) = **63.5 A**。

| 校核项 | 需求 | 能力（5×BNP-5120BM） | 结论 |
|--------|------|----------------------|------|
| 连续放电 | 119.5 A | 500 A | ✅ 裕量 4.2× |
| 短时放电 | 124.3 A | 500 A | ✅ |
| 最大充电 | 63.5 A | 250 A | ✅ 裕量 3.9× |

## 5. 敏感性复核

| 口径 | E_bat,min | 台数 |
|------|-----------|------|
| 3 d 自主供电 | 32.45 kWh | 7 |
| DOD=0.80 保守 | 24.34 kWh | 5 |
| K_T=0.70（设备间不保温） | 30.91 kWh | 7 |

> 结论：设备间保温（不低于 10 ℃）为必须；不保温时需 7 台（+43%），成本敏感性同拉萨。

## 6. 输出汇总

| 项目 | 结果 |
|------|------|
| 最低标称能量 | 21.64 kWh |
| 配置 | BNP-5120BM × 5（N_S=1，N_P=5），25.60 kWh |
| 连续/短时/充电电流 | 119.5 / 124.3 / 63.5 A |
| 设备间保温 | 必须（不低于 10 ℃） |
| 红线自查 | N_S=1；I_chg 按 MPPT 输出侧算；E_AC 不重复除以 eta_inv；1.18×≤1.25 ✅ |
