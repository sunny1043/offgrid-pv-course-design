# 拉萨设计总览（差异化对比：深圳 vs 拉萨）

> 本仓库原有全部设计均为深圳（W1–W6，E_AC=6.99 空调型）。本目录新增**拉萨**完整设计链，突出「城市、计算复核过程、后续设计」三方面的差异化。
> 状态：本地草稿（不提交 GitHub）。全部数据源与深圳一致：NASA POWER 2019–2023 五年平均 + Liu-Jordan 倾角模型 + 指导书/任务书口径。
> 设计点：**冬季采暖季 E_AC = 7.82 kWh/d（对应负荷区间 7.5~8.0，学号末位 4/5；区间可按学号末位微调）**。

## 一、关键差异一览

| 设计环节 | 深圳（原方案） | 拉萨（本方案） | 差异点 |
|---------|--------------|--------------|--------|
| 气候类型 | 亚热带海洋性，夏热冬暖 | 高原温带半干旱，冬寒夏凉 | 季节性负荷完全相反 |
| W1 负荷结构 | 夏季空调撑起高负荷 | **冬季电采暖**撑起高负荷 | 季节逻辑反转 |
| W1 E_AC（设计点） | 6.99 kWh/d（空调月） | **7.82 kWh/d（采暖季）** | 更高、冬季驱动 |
| W1 最大同时功率 | 3.0 kW | **4.6 kW** | 电采暖+炊事高峰 |
| W1 短时冲击功率 | 3.6 kW | **5.2 kW** | 更高 |
| W2 最不利设计月 | 10 月（R=1.63） | **12 月（R=1.85，水平面）** | 由「空调回落」变「采暖负荷+冬季辐照低」 |
| W2 年水平面辐照 | 约 1585 kWh/m2·yr | **约 1988 kWh/m2·yr**（全国顶级） | 资源更强 |
| W2 极端最低/最高温 | 0.2 / 38.7 ℃ | **-16.5 / 29.4 ℃** | 低温侧更严、高温侧更宽裕 |
| 倾角 | 20°（1.62×L） | **30°（2.13×L）** | 更陡、排间节距大 31% |
| W4 蓄电池下限 | 19.34 kWh（4 台） | **21.64 kWh（5 台）** | 冬季负荷更高多 1 台 |
| W4 低温修正 | K_T=1.00（无需论证） | **K_T=1.00（需保温设备间）+ 0.70 敏感性** | 新增低温设计决策 |
| W4 方案 B（200 Ah） | 2 台可满足 | **2 台不足、3 台超 1.25 倍上限，失效** | 城市差异导致组合失效 |
| W5 阵列容量 | 2.40 kWp（4 串） | **3.00 kWp（5 串）** | 更大、冬季余量 1.42 |
| W5 低温 Voc | 220.8 V（4 串） | **286.1 V（5 串）** | 低温更严、N_S 可行域 [4,7] vs [4,8] |
| W5 逐月供能比 | 最不利月 1.20；夏季 1.3~1.6 | **最不利月 1.42；夏季 2.8~4.4** | 夏季大富余（冬紧夏松） |
| W6 逆变器利用率 | 60% | **92%**（连续功率） | 更贴近额定 |
| W6 充电电流 | 42.4 A | **52.9 A** | 阵列更大 |
| W6 新增校核 | 无 | **高海拔 3650 m 功率降额 + 电池低温充电** | 深圳没有的检查点 |

## 二、本方案的「计算复核过程」差异化（答辩可讲）

1. **最不利月判定逻辑不同**：深圳=「空调月 10 月」；拉萨=「采暖月 12 月」，且 12 月辐照 4.23 仍高于深圳年均——**拉萨是负荷驱动的冬季最不利，不是辐照塌陷**；忽略采暖只看辐照会误选夏季（与深圳示例的误区正好相反）。
2. **蓄电池多一道低温校核**：设备间保温（不低于 10 ℃）是经济性关键；不保温 K_T=0.70 时容量需求 +43%（21.64→30.91 kWh），需多 2 台电池。
3. **光伏串联可行域收窄**：T_min=-16.5 ℃ 使 N_S,max=7（深圳 8），低温 Voc 校核是硬约束。
4. **高海拔降额**：3650 m 下逆变器/控制器需按厂家高原额定复核（常规降额后可能不足 4.6 kW），是深圳方案完全没有的校核。
5. **夏季弃光/能量管理**：5–9 月供能比 2.8~4.4，电池充满后弃光策略要写进运行说明。
