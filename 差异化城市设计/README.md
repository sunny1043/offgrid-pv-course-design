# 差异化城市设计（拉萨 / 兰州 / 哈尔滨）

> 本文件夹为户用离网光伏发电系统课程设计**新增的差异化城市方案**，与仓库 docs/ 下已有的深圳（基线）方案对应。
> 全部数据同一口径：NASA POWER 2019-2023 五年平均 + Liu-Jordan 倾角模型 + 指导书/任务书公式。
> 负荷设计点：冬季采暖 E_AC = 7.82 kWh/d（对应任务书区间 7.5~8.0，学号末位 4/5；可按分配区间微调）。
