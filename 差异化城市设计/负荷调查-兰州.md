# 负荷调查 — 兰州（差异化设计 · 冬季采暖版）

> 依据：任务书 §3.1、指导书 §2。状态：本地草稿。设计点：冬季采暖季 E_AC = 7.82 kWh/d（区间 7.5~8.0，学号末位 4/5，可按区间微调）。

## 0. 基本条件（兰州差异化核心）

| 项目 | 取值 | 说明 |
|------|------|------|
| 设计城市 | 兰州（36.05°N、103.83°E，海拔约 1520 m） | **8 度抗震设防区**，干燥少雨 |
| 气候 | 温带大陆性气候 | 1 月均温约 -5.8 ℃，7 月约 20.7 ℃ |
| 季节性负荷 | 冬季电采暖（11–3 月）+ 夏季轻度空调（6–8 月） | 与哈尔滨同为冬采暖、夏轻空调 |
| 采暖 | 电热毯 0.15 kW×8 h + 电暖器 1.2 kW×5 h×0.5 | 冬季必需，总量在区间内 |
| 空调 | 6–8 月午后 4 h×0.4（变频 1.5P，845 W） | 7 月均温 20.7 ℃，轻度空调 |

## 1. 负荷清单与日耗电（冬季口径）

| 类别 | 设备 | 日耗电(kWh/d) |
|------|------|--------------|
| 制冷空调 | 冰箱 0.54；空调（6–8 月）0.845×4×0.4=1.35 | 0.54 / 1.35（夏季） |
| 采暖 | 电热毯 1.20 + 电暖器 3.00 | 4.20（11–3 月） |
| 照明 | 0.38 | 0.38 |
| 通信 | 0.97 | 0.97 |
| 炊事 | 1.15 | 1.15 |
| 生活辅助 | 0.57 | 0.57 |
| **合计（采暖季）** | | **7.82** |

- 采暖季（11–3 月）7.82（✅）；过渡月（4、10）4.82；夏季（6–8）4.97；温和月（5、9）3.62。

## 2. 最大同时功率与短时冲击

- 冬季峰值（19:00–19:15 烧水 + 电暖器 + 电热毯 + 炊事 + 照明 + 电视 + 冰箱 + 路由）≈ **4.6 kW**；
- 周末电磁炉安排午餐（电暖器未开）≈ 3.6 kW < 4.6 kW；
- **P_max ≈ 4.6 kW**；P_short ≈ **5.2 kW**。

## 3. 输出汇总

| 结果 | 数值 |
|------|------|
| E_AC（冬季设计点） | 7.82 kWh/d |
| E_AC（过渡/夏季 AC/温和） | 4.82 / 4.97 / 3.62 kWh/d |
| P_max / P_short | 4.6 / 5.2 kW |

> 兰州与拉萨/哈尔滨差异点：同为冬季电采暖，但兰州冬季不如哈尔滨严寒（1 月均温 -5.8 ℃ vs -18.4 ℃），采暖需求略温和；夏季（7 月 20.7 ℃）轻度空调。兰州的关键差异化在**8 度抗震设防**（支架/屋面）与资源（冬春干燥少云，冬季辐照优于哈尔滨）。
