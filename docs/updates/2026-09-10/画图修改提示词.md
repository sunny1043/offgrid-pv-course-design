# 给同伴 Agent 的修改提示词

请根据 offgrid-pv-course-design 仓库中对应城市的最新报告、计算文件和现有图纸，检查并修改三张图：系统电气主接线图、光伏阵列及支架布置图、设备间平面及安装接线图。输出可编辑DXF和A3 PDF预览。

开始前阅读AGENTS.md、PROJECT_LOG.md、PROGRESS.md及本目录README，确认最新版本，保留他人原文件。

1. 型号、数量、串并联与计算书一致，不套用其他城市配置。
2. 接线完整，标清保护、线缆、正负极、L/N、PE和通信；交叉与连接明确，避免文字压线。
3. 一体机充放电共用电池端口，不虚构外接端子；哈尔滨两路PV分别接两台逆变器，标出并机通信。
4. 检查组件、安装缝、屋面边距、检修通道与设备净距。拉萨6m、哈尔滨12m屋面存在宽度矛盾，不得擅自加宽后声称现场满足。
5. 数据冲突、保护配合、结构承载、高原降额、保温耗电等未确认项标注待核实，不编造通过结论。

完成后逐页检查预览、重新读取DXF，并列出修改内容、依据和需负责人确认的事项；同步回填计算书、报告与BOM，避免只改图纸。
