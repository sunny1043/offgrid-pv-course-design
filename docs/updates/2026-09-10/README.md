## 必须一起交接的未决问题

1. **兰州文稿先于下午复核及R0图纸产生**。文稿不可当作所有参数已最终确认：5串标准工作电压约210V，所选德业手册的满载MPPT区间为300–425V，功率能力与恢复天数需要再核；普通MPPT工作范围合适不能直接证明满载能力。原4串电压推导中的保守下界也不足以独立证明4串必然失败。图纸说明中的限制应优先与文稿对照，后续统一回填。
2. **拉萨原6m屋面与哈尔滨原12m屋面不满足原定两侧边距**。加入20mm安装缝后，至少分别需要6750mm、12800mm宽；R1所画7000mm、13000mm为待确认备选，不是现场测量值。现场不能加宽则须重新布局与遮挡核算。
3. **充放电端口**：SPF一体机共用物理电池端口，不另设原C3功能计算所对应的外部充电端口。相关W7、清单与成本需要同步修订，不能照旧采购重复回路。
4. **保护与适用性**：电池短路分断/选择性、母排额定电流、SPD配合、RCD类型、N-PE与故障切断、BMS协议、双机同步，以及拉萨高原额定能力均未完成厂家及工程复核。
5. **结构及热工**：屋面承载、风雪、锚固、防水以及保温/加热/通风耗电需继续闭合。不能据初稿宣称满足施工或自治天数。
6. **实验**：本次没有新增实测原始数据，不将W10实验标记完成。
