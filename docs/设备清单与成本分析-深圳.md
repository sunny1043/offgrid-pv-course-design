## 2. 蓄电池两种配置比较（任务书 §4.8 要求）

| 配置 | 模块 | 能量 | 电池成本 | 支路保护 | 说明 |
|------|------|------|---------|---------|------|
| **方案 A（采用）** | 4×BNP-5120BM（100 Ah） | 20.48 kWh | **¥16,000** | 4 支路 | 官方渠道/质保好；W5~W9 全部校核与图纸均按此配置 |
| 方案 B（备选） | 2×51.2 V/200 Ah | 20.48 kWh | ≈¥13,000 | 2 支路 | madeinchina 报价 $900/台≈¥6,500，电池省 ≈¥3,000，支路保护/母排更少 |

> **结论**：方案 B 初始成本低约 ¥3,000~4,000，但方案 A 为官方渠道产品、参数齐备且**已用于 W4~W9 全部校核与图纸（数据一致性红线）**，本设计维持方案 A；报告中说明 B 为降本备选，若改选 B 需同步更新电流校核与图纸。

## 3. 成本分析（指导书 §12.1）

| 指标 | 数值 |
|------|------|
| 系统初始总投资 | **≈ ¥26,945** |
| 单位装机成本 | ≈ ¥26,945 / 2.40 kWp = **¥11.2/Wp** |
| 单位储能成本 | ¥16,000 / 20.48 kWh ≈ **¥781/kWh**（仅电池） |
| 成本结构 | 蓄电池 64%（含柜体）＞ 光伏阵列 10% ＞ 控制变换 8% ＞ 其余 18% |

> 电池占系统成本约 2/3 是离网系统的典型特征（能量密度与寿命决定），也解释了为何 3 d 敏感性方案成本显著上升。

## 4. 成本过高检查（指导书 §12.2 顺序）

1. 负荷在 6.5~8.5 范围内且空调时长合理 ✅（E_AC=6.99，空调 8 h/d）；
2. 未把 3 d 作为基准容量 ✅（3 d 仅敏感性）；未重复计算损失 ✅；
3. 电池模块粒度与支路数已比较（A/B 方案）✅；
4. 未以取消保护/扩大 DOD/超电流限值降本 ✅；
5. 如需进一步降本优先级：电池 B 方案（-¥3,000~4,000）→ 组件等低价期采购 → 支架自装。
