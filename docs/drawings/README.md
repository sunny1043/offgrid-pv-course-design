## 三、图纸与 W4–W8 数据一致性（任务书红线：报告/图纸/设备清单一致）

**深圳：**
- 光伏组件：隆基 LR7-72HGD-600M ×4（4 串×1 并，2.40 kWp）——W5；
- 蓄电池：Benhoo BNP-5120BM ×4（51.2V/100Ah/5.12kWh）——W4；
- 控制器/逆变器：Growatt SPF 5000 ES（5kW/10kVA/η93%，MPPT 120~430V）——W6；
- 线缆/保护：PV1-F 4mm²（光伏）、RV 10/70mm²（电池侧）、RVV 3×6mm²（交流）、F1 25A gPV、F2-F5 100A、QF1 160A DC MCB、QF2 32A、RCD 30mA、SPD 两级——W7；
- 支架/布置：倾角 20°、单排 4 块、排距 1.84m、设备间 3.0×2.5m——W8。

**拉萨（W7/W8 参数）**：PV1-F 4mm²、组串 F1 25A gPV、电池→逆变器 RV 70mm² + QF1 160A DC MCB、支路熔断器 F2-F6 5×100A gPV、直流 SPD U_cpv≥345V；交流 6mm²+32A、采暖插座 10A/2.5mm²；倾角 30°、竖排 5 块、排距 D=5.09m、设备间 3.0×2.5m（保温≥10℃）。

**兰州（W7/W8 参数）**：PV1-F 4mm²、组串 F1 25A gPV、电池→逆变器 RV 70mm² + QF1 160A DC MCB、支路熔断器 F2-F6 5×100A gPV、直流 SPD U_cpv≥420V；交流 6mm²+32A、采暖插座 10A/2.5mm²；倾角 30°、竖排 6 块、排距 D=5.98m、设备间 3.0×2.5m（8 度抗震锚固）。
