# 课程设计任务内容与认领清单

> 户用离网光伏发电系统 · 2026 专业课程创新研修课程设计（多人协作）
> 本文档依据四份原始资料整理：任务书 / 设计指导书 / 进度检查与考核标准 / 实验测试。
> 状态：本地草稿，未上传仓库。

---

## 一、总体任务

为一个中国城市普通住宅设计**完全离网**的户用光伏发电系统（单相 220V/50Hz、48V 级磷酸铁锂蓄电池、2 d 自主供电、3 d 敏感性分析、按最不利设计月定光伏容量），交付 7 项成果：

1. 课程设计报告（Word + PDF）
2. 工程图纸 3 张 A3（T1-01 主接线图 / T1-02 阵列及支架布置图 / T1-03 设备间平面及安装接线图，源文件 + PDF）
3. 计算文件（Excel，公式可检查）
4. 实验资料（原始记录、照片、数据文件）
5. 产品与价格资料（规格书/网页/报价日期）
6. 最终提交文件夹（按学号、姓名、任务、城市命名）

## 五、验收与质量门禁

- **100 分构成**：过程与出勤 10 / 技术设计 35 / 工程图纸 25 / 实验 15 / 报告与答辩 15；
- **9 项最终自查**（考核标准 §八 表6）：负荷区间、来源、蓄电池复核、高低温电压、MPPT 两侧、设备参数、三图+源文件、三文件一致、实验齐全；
- **8 条严重问题红线**（§五）：缺图缺报告 / 负荷出区间 / 完整 51.2V 模块违规串联 / 光伏电流当充电电流 / 电池电压×光伏电流算功率 / 低温 Voc 超控制器耐压 / 图纸缺保护线缆参数 / 抄袭；
- **答辩 12 问**（§七）：全部能用个人数据解释。
