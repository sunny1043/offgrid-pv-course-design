2. 最大同时功率（指导书 §2.3）

P_j = Σ(该时段同时运行 P_i)；P_max = max_j P_j

19:00-19:15 烧水时段完整代入：电暖器 1.2 + 电热毯 0.15 + 电热水壶 1.5 + 电饭煲 0.86 + 油烟机 0.20 + 照明 0.072 + 电视 0.12 + 冰箱 0.12 + 路由器 0.006 = 4.228 ≈ 4.2 kW。

周末校核（电磁炉午餐、电暖器未开）：2.1 + 0.86 + 0.20 + 0.072 + 0.12 + 0.12 + 0.006 + 0.04 = 3.518 ≈ 3.5 kW < 4.2 → P_max = 4.2 kW。

数据来源：设备功率见 §2.1（官方链接）；错峰在 24 h 运行表体现（指导书 §2.3 要求）。

3. 短时冲击功率（指导书 §2.4）

P_start,m = k_s,m × P_m,rated；P_short = P_start + 同时运行其他负荷

冰箱压缩机启动：k_s ≈ 5 × 0.12 kW = 0.60 kW（持续约 0.1~0.5 s）。

P_short = 4.228 + 0.60 = 4.83 ≈ 4.8 kW。

数据来源：k_s、t_start 按厂家资料（海尔冰箱/洗衣机-苏宁/美的空调商城链接在 §2.4 表）；变频空调软启动不套定频倍数。

4. 峰值日照时数（指导书 §3.1）

H = G_tilt / 1(kW/m²)；数值上 h/d = kWh/m²·d

水平面 12 月：G=2.82 kWh/m²·d → 2.82 h/d。

倾斜 35° 面 12 月：Liu-Jordan 换算 G_tilt = B·R_b + D·(1+cos35°)/2 + G·ρ·(1−cos35°)/2，代入 NASA 实测 G=2.82、D=0.96（B=1.86）、ρ=0.2、R_b 按时角积分 → 4.81 kWh/m²·d → 4.81 h/d。

数据来源：NASA POWER 逐月 G/D（2026-09-06 实测）；PVGIS 交叉验证 ±10% 量级（文档 §3.1）。

5. 最不利设计月（指导书 §3.2）

R_m = E_AC,m / G_m

逐月代入（G 为 NASA 实测）：1 月 7.605/3.00=2.54；2 月 7.605/3.74=2.03；3 月 7.605/4.83=1.58；4 月 4.605/5.51=0.84；5 月 3.405/6.00=0.57；6 月 4.419/5.90=0.75；7 月 4.419/6.20=0.71；8 月 4.419/5.19=0.85；9 月 3.405/4.62=0.74；10 月 4.605/3.51=1.31；11 月 7.605/3.22=2.36；12 月 7.605/2.82=2.70（最大）→ 最不利设计月 = 12 月。

数据来源：E_AC 逐月（§1）；G 逐月（NASA 实测）。

6. 组件温度（指导书 §3.3，NOCT）

T_cell = T_amb + (NOCT−20)/800 × G（NOCT=45 ℃、G=1000 W/m²）

温升项：(45−20)/800 × 1000 = 25/800×1000 = 0.03125×1000 = 31.25 ℃。

极端高温：T_cell = 39.8 + 31.25 = 71.05 ≈ 71.1 ℃；7 月常态：20.7 + 31.25 = 51.95 ≈ 51.9 ℃。

数据来源：T_amb 为兰州市气象记录（39.8 ℃）与 NASA 月均温（20.7 ℃）；NOCT 为组件典型参数。

7. 综合路径效率（指导书 §4.2）

η_path = η_dc·η_MPPT·η_ch·η_dis·η_inv·η_ac

逐项相乘：0.98×0.96=0.9408；×0.95=0.89376；×0.95=0.849072；×0.93=0.789637；×0.99=0.78174 ≈ 0.782。

数据来源：η_inv=0.93（Growatt 官方数据表）；η_dis=0.95（LFP 往返效率典型值）；线缆/控制器/充电效率为设计取值（文档 §4.2）。

8. 蓄电池最低标称能量（指导书 §5.2）

E_bat,min = E_AC·N_A·K_R / (DOD·η_dis·η_inv·K_T)

分子：7.605 × 2 × 1.10 = 15.210 × 1.10 = 16.731。

分母：0.90 × 0.95 × 0.93 × 1.00 = 0.855 × 0.93 = 0.79515。

E_bat,min = 16.731 / 0.79515 = 21.04 kWh。

数据来源：E_AC=7.605（§1）；N_A=2（任务书）；K_R=1.10（BNP-5120BM 循环 6000+ 次、70% EOL 预留衰减）；DOD=0.90（Benhoo 放电下限 44.8 V）；η_dis=0.95（LFP 典型）；η_inv=0.93（Growatt）；K_T=1.00（模块充电 0~50 ℃、保温≥10 ℃）。

9. 安时换算（指导书 §5.2）

C_bat,min = 1000 × E_bat,min / V_nom

代入：1000 × 21.04 / 51.2 = 21040 / 51.2 = 410.9 ≈ 411 Ah。

数据来源：V_nom=51.2 V（Benhoo 官方规格）。

10. 模块能量与并联数（指导书 §5.3）

E_mod = V·Ah/1000；N_P,E = ceil(E_bat,min / E_mod)

E_mod = 51.2 × 100 / 1000 = 5120/1000 = 5.12 kWh。

N_P,E = ceil(21.04 / 5.12) = ceil(4.109) = 5 台；实际 = 5 × 5.12 = 25.60 kWh；比值 = 25.60/21.04 = 1.217 ≈ 1.22（≤1.25 ✓）。

方案 B（200 Ah）：E_mod=10.24 kWh；2 台 = 2×10.24 = 20.48 kWh < 21.04（不足）；3 台 = 3×10.24 = 30.72 kWh，30.72/21.04 = 1.46 > 1.25（超限）→ 不成立。

数据来源：模块 Benhoo BNP-5120BM（官方产品页链接在文档 §5.3）；1.25× 上限（指导书 §5.5）。

11. 充放电电流（指导书 §5.4）

I_dis = P_inv,r/(V_bat,min·η_inv)；短时用 P_short；I_chg = min(P_PV·η_MPPT/V_bat,chg, I_ctrl)

分母：45 × 0.93 = 41.85。

连续放电 I_dis = 5000 / 41.85 = 119.5 A。

短时放电 I_dis,sur = 4800 / 41.85 = 114.7 A（4800 W 即 P_short=4.8 kW）。

最大充电 I_chg = min(2400 × 0.96 / 54.4, 80) = min(2304/54.4, 80) = min(42.35, 80) = 42.4 A。

并联数量：N_P,dis = ceil(119.5/100) = 2；N_P,chg = ceil(42.4/50) = 1；N_P = max(5, 2, 1) = 5。

校核：连续 119.5 ≤ 5×100=500（4.2×）；短时 114.7 ≤ 500；充电 42.4 ≤ 5×50=250（5.9×）→ 全部通过。

数据来源：P_inv,r=5000 W、η_inv=0.93、I_ctrl=80 A（Growatt 官方数据表）；P_short=4800 W（§3）；V_bat,min=45 V、V_bat,chg=54.4 V（逆变器/模块规格）；P_PV=2400 W、η_MPPT=0.96（附录 A）。

12. 3 d 敏感性分析（指导书 §5.5）

E_3d = E_AC·3·K_R / (DOD·η_dis·η_inv·K_T) ≈ 1.5 × 2 d 基准

分子：7.605 × 3 × 1.10 = 22.815 × 1.10 = 25.0965；分母 0.79515。

E_3d = 25.0965 / 0.79515 = 31.56 kWh；N_P,E = ceil(31.56/5.12) = ceil(6.164) = 7 台（35.84 kWh），较方案 A 多 2 台；31.56/21.04 = 1.50 倍（理论 3/2）。

保守 DOD=0.80：16.731 / (0.80×0.95×0.93) = 16.731 / 0.7068 = 23.67 kWh → 5 台。

低温 K_T=0.70（不保温）：16.731 / (0.90×0.95×0.93×0.70) = 16.731 / 0.5566 = 30.06 kWh → 6 台（较基准 +43%）。

数据来源：系数同 §8（查得来源）；3 d 仅观察成本变化、不作最终配置（任务书明确）。

13. 附录A 光伏（供 §11 电流，指导书 §6）

P_PV,min = E_AC·K_R/(H_tilt·η_path)

代入：7.605×1.10 / (4.81×0.782) = 8.3655 / 3.7614 = 2.22 kWp；选 N_S=4（600 W×4 = 2.40 kWp）。

V_oc,cold = V_oc·(1+β_Voc·(T_min−25))；V_mp,hot = V_mp·(1+β_Vmp·(T_cell−25))

V_oc,cold = 52.22×(1+(−0.0023)×(−21.7−25)) = 52.22×(1+0.0023×46.7) = 52.22×1.10741 = 57.83 V；V_mp,hot = 44.12×(1−0.0028×46.1) = 44.12×0.87092 = 38.43 V；V_mp,cold = 44.12×1.13076 = 49.89 V。

N_S,min = ceil(120/38.43) = 4；N_S,max = floor(500/57.83) = 8 → 可行域 [4,8]；选 N_S=4 → 组串 V_oc,cold = 4×57.83 = 231.3 V ≤ 500 V ✓。

12 月供能 E_PV = 2.4 × 4.81 × 0.782 = 9.03 kWh/d；供能比 = 9.03 / 7.605 = 1.19（1 月 1.17）。

数据来源：组件隆基 LR7-72HGD-600M（V_oc=52.22 V 等，官方数据表）；控制器上限 500 V（Growatt 官方数据表）；T_min=-21.7 ℃、T_cell=71.1 ℃（§6）。
