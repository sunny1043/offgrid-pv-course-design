# 兰州 D1~D5 公式计算汇总（指导书 §1~§5 + 附录A 光伏）

> 数据：NASA POWER 2026-09-06 实测（2019-2023 五年平均，36.05N/103.83E）；极端气温 39.8 ℃（2010-07-28）/ -21.7 ℃（1964-01-27）；负荷为兰州专属并经官网核验。全部输入与来源见《兰州-D1-D5-按指导书执行版.docx》。
> 参数声明：全部数据按实际查得来源计算（NASA POWER 实测、兰州市气象记录、官方产品页、Growatt/Benhoo 官方数据表），未采用指导书 §5.2 示例数值；如个别工程常值与示例相同属正常取值。

## 0 设计输入（含来源）
- 冬季 E_AC = **7.61 kWh/d**（区间 7.5~8.0，学号末位 4/5）；过渡 4.61、夏季 4.42、温和 3.41
- 基础负荷 3.41 = 0.54(冰箱) + 0.32(照明) + 0.82(通信) + 1.14(炊事) + 0.59(生活辅助)；采暖 4.20 = 1.20 + 3.00
- 气候：NASA POWER（https://power.larc.nasa.gov ）；PVGIS 交叉验证（https://re.jrc.ec.europa.eu/pvg_tools/en/ ）
- 极端气温：39.8 ℃（https://weather.news.sina.com.cn/news/2010/0729/57728.html ）；-21.7 ℃（https://m.thepaper.cn/newsDetail_forward_10881660 ）
- 设备功率来源见执行版 §2.1 表（内联链接）

## 1 日用电量（指导书 §2.2）
**公式**：E_i = P_i × t_i × k_i（kWh/d，P:kW、t:h）；E_AC = Σ E_i
**计算**：
- 基础 3.41；采暖月 E_AC = 3.41 + 4.20 = **7.61 kWh/d**
- 过渡 3.41+1.20 = 4.61；夏季 3.41+1.01 = 4.42；温和 3.41

## 2 最大同时功率（指导书 §2.3）
**公式**：P_j = Σ(该时段同时运行 P_i)；P_max = max_j P_j
**计算**：19:00-19:15 峰值 = 1.2+0.15+1.5+0.86+0.20+0.072+0.12+0.12+0.006 = **4.23 ≈ 4.2 kW**（周末 3.5 kW）

## 3 短时冲击功率（指导书 §2.4）
**公式**：P_short = P_start,k + 同时运行其他负荷
**计算**：4.23 + 0.60（冰箱 5 倍×0.12）= **4.83 ≈ 4.8 kW**

## 4 峰值日照时数（指导书 §3.1）
**公式**：H = G_tilt / 1(kW/m²)，数值上 h/d = kWh/m²·d
**计算**：水平 12 月 2.82；倾斜 35° 12 月 **4.81 h/d**（Liu-Jordan，NASA 实测散射）

## 5 最不利设计月（指导书 §3.2）
**公式**：R_m = E_AC,m / H_m
**计算**：12 月 R = 7.61/2.82 = **2.70**（全年最大）→ 最不利设计月 = 12 月

## 6 组件温度（指导书 §3.3，NOCT）
**公式**：T_cell = T_amb + (NOCT−20)/800 × G（NOCT=45 ℃、G=1000 W/m²）
**计算**：极端 39.8 → 71.1 ℃；7 月常态 20.7 → 51.9 ℃

## 7 综合路径效率（指导书 §4.2）
**公式**：η_path = η_dc · η_MPPT · η_ch · η_dis · η_inv · η_ac
**计算**：0.98×0.96×0.95×0.95×0.93×0.99 ≈ **0.782**

## 8 蓄电池最低标称能量（指导书 §5.2）
**公式**：E_bat,min = E_AC·N_A·K_R / (DOD·η_dis·η_inv·K_T)
**系数来源（查得数据，非指导书示例）**：N_A=2（任务书统一条件）；K_R=1.10（Benhoo BNP-5120BM 循环 6000+ 次、寿命期末容量保持率约 70% EOL → 预留衰减余量）；DOD=0.90（厂家规格放电下限 44.8 V、智能 BMS 允许深度循环）；η_dis=0.95（磷酸铁锂往返效率典型值）；η_inv=0.93（Growatt SPF 5000 ES 官方数据表峰值）；K_T=1.00（模块充电工作温度 0~50 ℃，设备间保温≥10 ℃ 无低温损失）。
**计算**：7.61×2×1.10 / (0.90×0.95×0.93×1.00) = 16.742/0.79515 ≈ **21.04 kWh**

## 9 安时换算（指导书 §5.2）
**公式**：C_bat,min = 1000 × E_bat,min / V_nom
**计算**：1000×21.04/51.2 ≈ **411 Ah**

## 10 模块能量与并联数（指导书 §5.3）
**公式**：E_mod = V·Ah/1000；N_P,E = ceil(E_bat,min / E_mod)
**计算**：E_mod = 51.2×100/1000 = 5.12 kWh；N_P,E = ceil(21.04/5.12) = **5 台**；实际 25.60 kWh = **1.22×**（≤1.25）

## 11 充放电电流（指导书 §5.4）
**公式**：I_dis = P_inv,r/(V_bat,min·η_inv)；短时用 P_short；I_chg = min(P_PV·η_MPPT/V_bat,chg, I_ctrl)；N_P = max(N_P,E, N_P,dis, N_P,chg)
**计算**：
- I_dis = 5000/(45×0.93) = **119.5 A**
- I_dis,sur = 4800/(45×0.93) = **114.7 A**
- I_chg = min(2400×0.96/54.4, 80) = **42.4 A**
- N_P,dis=2、N_P,chg=1 → N_P = max(5,2,1) = **5**

## 12 敏感性（指导书 §5.5）
**公式**：3 d ≈ 1.5 × 2 d 基准
**计算**：3 d = 31.56 kWh → 7 台；DOD=0.80 → 23.67 kWh → 5 台；K_T=0.70 → 30.06 kWh → 6 台

## 附录A 光伏阵列（供 §5.4 电流校核，指导书 §6）
**公式**：P_PV,min = E_AC·K_R/(H_tilt·η_path)；V_oc,cold = V_oc·(1+β_Voc·(T_min−25))；V_mp,hot = V_mp·(1+β_Vmp·(T_cell−25))；N_S,min=ceil(V_MPPT,min/V_mp,hot)；N_S,max=floor(V_ctrl,max/V_oc,cold)
**计算**：
- P_PV,min = 7.61×1.10/(4.81×0.782) ≈ **2.23 kWp**
- V_oc,cold = 52.22×(1+0.0023×46.7) ≈ 57.83 V；V_mp,hot ≈ 38.43 V；V_mp,cold ≈ 49.89 V
- N_S,min=4、N_S,max=floor(500/57.83)=8 → 可行域 [4,8]；选 N_S=4、N_P=1 → **2.40 kWp**，12 月供能比 = 2.4×4.81×0.782/7.61 ≈ **1.19**（1 月 1.17）
- I_chg = min(2400×0.96/54.4, 80) = 42.4 A（回填 §5.4）
